# study with soobin

A cozy Pomodoro study app with TXT videos, a task checklist, music and ambience,
and a local profile with XP, levels, milestones, and lifetime study hours.

**Windows:** download [StudyWithSoobin.exe](StudyWithSoobin.exe) and run it.
Videos and music need an internet connection. Your tasks, preferences, and
progress stay on your device.

All project documentation lives in [docs](docs/README.md):

- [App guide: features, setup, and desktop builds](docs/app-guide.md)
- [Screenshots and feature walkthrough](docs/screenshots.md)
- [Profile levels and XP rules](docs/LEVELS.md)
- [TXT video catalog](docs/video-catalog.md)

For development, run `npm install` and `npm run dev`.
